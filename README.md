# BTC v53 真钱版：本金可追加

版本 `1.1.0-live-flex.1`，2026-10-07。BTC-USDT 永续，逐仓 15 倍，真实账户、真实订单。

这版取消了累计本金固定为 30U 的限制。默认第一次分配 30U；以后向专用交易账户转入 USDT，再执行 `sync-capital`，核对通过后才增加策略可用本金。比如 30U + 后来确认转入的 100U = 累计投入 130U。盈利不会被重复算成本金，转入也不会被当成盈利。

它没有取消止损或其他风控：15 倍杠杆、原 v53 信号、6% 计划风险、60% 回撤停止、默认 30U 累计净亏损停止阈值均保留。追加资金不自动调高 30U 亏损阈值。阈值是程序停止条件，并非实际最大损失保证；名义仓位和订单仍受交易所规格与原策略规则约束。

## 先做哪一步

1. 你确认旧 v53 只有启用前的 1U 小单测试，没有策略成交。先按 [清理旧版](docs/CLEAN-OLD.md) 停止、核对、删除旧版。
2. 清理成功后再解压本包到 `~/btc-v53-live`，按 [安装新版](docs/DEPLOY.md) 配置 API、检查和启用。
3. 后续看 [日常操作与追加资金](docs/OPERATIONS.md)。最常用命令仍是 `python3 "$HOME/btc-v53-live/launch.py" status`。

清理工具仅适用于从未产生策略成交、资金费或损失的旧版，运行时还会向欧易核对。不符合时会拒绝删除，不能靠删除账本绕过风控。

## 文件与服务

| 项目 | 位置或作用 |
|---|---|
| 程序目录 | `/home/dvens/btc-v53-live` |
| 统一入口 | `launch.py`，检查、查看、启用、运行、同步本金 |
| 配置 | `config.json`，初始本金、亏损阈值和代理地址；启用后不要修改 |
| API 密钥 | `credentials.env`，在服务器交互输入；包内不含真实密钥 |
| 账本 | `var/live/state.sqlite3`，保存成交、盈亏、追加本金、委托和运行状态 |
| 用户后台服务 | `btc-v53-live.service`，无需 sudo 管理 |
| 代理 | 复用 `mihomo-proxy.service`，入口 `http://127.0.0.1:17890` |

本包无需重装 Mihomo，不改 F3 服务或 F3 API。v53 应使用与 F3 分开的交易账户/子账户。
